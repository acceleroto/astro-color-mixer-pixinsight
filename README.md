# Astro Color Mixer PixInsight Repository

Astro Color Mixer is a nonlinear RGB color and luminance refinement tool for astrophotography.

This repository folder is intended to become the PixInsight update repository package structure.

Beta version:
v0.9.7.3-beta

Installed script path:
src/scripts/CosgrovesCosmos/AstroColorMixer.js

Resource path:
rsc/AstroColorMixer/

Repository update files will later be placed in:
updates/

## Documentation

Astro Color Mixer v0.9.7.3-beta includes documentation in three forms:

1. Markdown documentation:
   `rsc/AstroColorMixer/docs/`

2. Static HTML documentation:
   `rsc/AstroColorMixer/docs/html/`

3. Starter PIDoc source:
   `doc/scripts/CosgrovesCosmos/AstroColorMixer/`

For this beta, Markdown and in-script help are the primary supported documentation. The PIDoc source is included to prepare for formal PixInsight documentation integration in a later release.
