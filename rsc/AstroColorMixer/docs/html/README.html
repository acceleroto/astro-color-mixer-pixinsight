Astro Color Mixer for PixInsight

Nonlinear RGB color refinement for astrophotography

Overview

Astro Color Mixer is a PixInsight script for nonlinear RGB color and luminance refinement in astrophotography. It is built for controlled finishing work on color bands, luminance ranges, and sequential refinement passes.

  • Color-band Hue, Saturation, and Luminance controls
  • Neutral / Low-Saturation luminance adjustment
  • Selected Band width and feather
  • Range Mask targeting
  • Refinement Passes, diagnostics, and mask views
  • Adjustment Set save/load

Intended Input

Use Astro Color Mixer on nonlinear RGB images after calibration, integration, background correction, color calibration, and stretch. It is not intended for raw linear calibration work.

Both Stars Present and Starless workflows are supported.

Basic Workflow

  1. Open a nonlinear RGB image.
  2. Choose Image Type.
  3. Start with Base Pass.
  4. Use H/S/L controls for broad changes.
  5. Use the probe, histogram, and polar plot.
  6. Refine Width and Feather.
  7. Use Range Mask for luminance targeting.
  8. Add Refinement Passes for targeted work.
  9. Use Preview, mask views, and Original/Adjusted comparison.
  10. Apply to New Image and save an Adjustment Set if useful.

Stars Present vs Starless

Stars Present is the safer mode for images that still contain normal stars, bright cores, and halos. Starless allows more freedom for nebulae, galaxies, dust, and faint structures after stars have been removed.

This setting does not remove stars and does not create a star mask. It changes protection behavior during adjustment.

Known Limitations

  • Not intended for linear calibration
  • Extreme hue or saturation changes can create artifacts
  • Preview is downsampled
  • Range Mask depends on stretch
  • Low-saturation pixels have unreliable hue
  • Beta software should be used non-destructively
