Astro Color Mixer Technical Appendix

Introduction

This appendix describes the practical processing model used by Astro Color Mixer for nonlinear RGB astrophotography refinement.

Design Goals

  • Controlled nonlinear RGB refinement
  • Astro-specific color-band workflow
  • Reduced arbitrary global color swings
  • Support for both stars-present and starless workflows
  • Visible masks and diagnostics
  • Non-destructive output-to-new-image workflow

Processing Assumptions

  • Nonlinear RGB input
  • Normalized floating-point RGB values in the range 0..1
  • Source image is not overwritten
  • Preview uses downsampled data
  • Final Apply uses full resolution

Image Type

Stars Present is more conservative around bright stellar structures. Starless allows more freedom in nebulae, galaxies, dust, and faint structures after stars have been removed. This setting does not detect, remove, or mask stars.

Luminance Model

Y = 0.2126 R + 0.7152 G + 0.0722 B

Luminance is used for Range Mask construction, preview diagnostics, neutral luminance shaping, and protection terms.

Hue Band Mask

distance = circularHueDistance(hue, center)
mask = 1 - smoothstep(innerWidth, outerWidth, distance)

Width controls span, Feather controls falloff softness, and a smoothstep-like transition keeps boundaries usable for nonlinear editing.

Selected Band Spatial Blur

Selected Band Blur is an optional spatial blur applied to the active band's final mask. It is not part of hue selection and is not a luminance Range Mask control.

Feather softens hue-distance falloff. Range Mask Feather softens luminance-range boundaries. Selected Band Blur smooths the already-built band mask across neighboring image pixels.

The implementation uses modest whole-pixel radii only: Off, 1 px, 2 px, 3 px, 4 px, or 5 px. It is applied only when Image Type is Starless.

rawBandMask = hueMask * saturationReliability * protection * rangeMask
if imageType == starless and selectedBandBlur > 0:
    workingBandMask = spatialBlur(rawBandMask, selectedBandBlur)
else:
    workingBandMask = rawBandMask

Range Mask

leftRamp = smoothstep(low - feather, low, Y)
rightRamp = 1 - smoothstep(high, high + feather, Y)
rangeMask = clamp01(leftRamp * rightRamp)

Low and High define the target interval. Feather softens both edges. Presets are starting points.

Neutral / Low-Saturation Model

neutralMask = 1 - smoothstep(satStart, satFull, saturation)

This luminance-focused path is used when hue is unreliable in weak-color pixels.

Chroma-Vector Adjustment

Conceptually, Astro Color Mixer separates a luminance-like neutral component from chroma, scales saturation, rotates hue, adjusts luminance, then recombines and clamps to valid RGB.

Combined Mask

finalMask =
  hueMask *
  saturationReliability *
  darkProtection *
  highlightProtection *
  rangeMask

Low-Saturation Galaxy Case

Some broadband galaxies have real but weak color in outer arms, dust, and faint halos. Protect Low Sat reduces hue-band slider response when saturation is low because hue is less reliable there.

Turning off Protect Low Sat can help extract faint galaxy color, but it increases the risk of blotchy color, noisy hue patches, and colored star halos. Use starless data when possible, inspect masks, and prefer multiple smaller passes over one extreme pass.

If Selected Band Blur is active, the band mask is spatially blurred after these terms are combined and before the color adjustment is applied.

Refinement Passes

working = original
for each enabled pass:
    working = applyPass(working, pass)

Passes are sequential and support broad setup followed by targeted cleanup.

Limitations

  • Not for linear calibration
  • Extreme changes can artifact
  • Preview is approximate
  • Hue is unreliable in neutral areas
  • Range Mask depends on stretch
  • Saturated star cores require care
  • Beta software status
